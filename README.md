# shadowrocket-auto

自动收集公共节点，并在本地生成 Shadowrocket 订阅。

## 订阅发布状态

出于凭据保护考虑，本仓库暂不公开发布节点订阅文件。采集结果只在运行环境本地生成，不会提交到 Git 历史；公开工作流仅更新不含节点 URI 的聚合质量报告。请不要把本仓库的公开地址当作可用订阅地址。

如需个人使用，请在可信环境本地运行采集器，并自行通过私有仓库或有访问控制的渠道托管订阅。不要把真实 UUID、密码或私有节点 URI 提交到公开仓库。

## 安全说明

- 订阅源响应上限 2 MiB；每源最多 5,000 条、总计最多 20,000 条候选；单行最多 8 KiB。
- 最多处理 50 个订阅源、并发抓取 10 个；每轮最多检测 5,000 个去重候选节点，超出部分会在质量报告中计入 `skipped_limit`，避免大量恶意/重复节点拖垮定时任务。
- 单个订阅源下载总时限为 20 秒，覆盖首次请求、重试及重试等待（连接/读取超时也不会超过剩余总预算）；并发抓取按批次进行，达到总节点上限后停止后续批次。
- DNS 主机名会先做 IDNA 和标签格式校验；拒绝选项注入形式、空标签及非法字符，再调用 `getent` 做解析。
- 订阅源仅允许 HTTPS `raw.githubusercontent.com`，禁止自动跟随重定向，避免恶意源配置或跳转访问内网/本机服务。
- 域名解析通过 `getent ahosts` 子进程执行，硬超时为 2 秒；超时会终止解析进程并计入 timeout，不会无限占用采集线程。运行环境需要提供 `getent`（GitHub-hosted Ubuntu runner 默认具备）。
- VMess 主机和端口进行严格类型/范围校验；单个异常节点不会中断整批任务。
- DNS 答案只要包含非公网地址就拒绝；连接时使用已校验的解析结果。
- 每个节点有连接总时限，防止多地址轮询无限拖延。
- 公开工作流只提交不含节点 URI 的聚合质量报告；订阅文件不进入 Git 跟踪或公开发布。
- 订阅文件和质量报告均先写入同目录临时文件，再通过原子替换落盘，避免中断时覆盖成半截文件；质量报告仅在订阅成功替换后标记 `updated`。
- 无可用节点时保留上一版订阅；报告会标注订阅是否更新。

**重要：Base64 不是加密。** 公开仓库中的订阅任何人都能解码，节点 URI 可能包含 UUID、密码和服务器地址。请只发布你有权公开的节点。私用订阅应使用私有仓库或受访问控制的发布渠道。如果历史提交曾含明文节点或真实凭据，仅删除当前文件不足以消除泄露，应轮换凭据并清理 Git 历史。

DNS 检查只在收集时发生；客户端稍后会重新解析域名，因此无法保证发布后 DNS 不变。不要简单把域名替换成 IP，否则可能破坏 TLS SNI、Host 或证书验证。

## 检测与排名

每小时任务先对 TCP 节点进行三次建连采样（至少两次成功），计算中位延迟和抖动；Hysteria2/Hy2、TUIC 等 UDP 节点不再冒充 TCP 可达。随后使用固定版本且 SHA-256 校验的 sing-box，在本机回环地址启动隔离的代理入口，通过真实代理隧道对候选节点下载 Cloudflare 测试数据（每节点最多两次、每次 256 KiB）。当前每轮最多测速 200 个候选节点（按大陆可用性档位配额抽取：A 档 VLESS Reality 与 443 端口 TLS 占 100、B 档其他 TLS 占 40、C 档占 40、UDP 占 20，某档不足时按档位顺序补位；档内按协议均衡，且每档名单按小时种子轮换切片，避免每小时重复测同一批节点），测速为 4 路并行（同一出口带宽分摊会使 Mbps 数值略低于串行，只作粗排），总测速阶段设有 10 分钟硬预算。测速前重新校验 DNS 公网地址，并将 sing-box 连接目标固定到已验证 IP，避免 DNS 重绑定绕过地址过滤。只有完成完整下载的节点才进入订阅，订阅按档位、再按实测 Mbps 排序；失败或不支持的节点不会伪造速度，也不会进入本轮新订阅。档位只是按协议/传输/端口的启发式排序，节点 IP 是否已被封锁无法从境外测得，大陆实际可用性不作保证。若没有节点通过测速，则保留上一版订阅。

当前转换器覆盖常见 VLESS（TLS/Reality、WS/gRPC/HTTP 传输）、Trojan、VMess、Shadowsocks（无插件）、Hysteria2 和 TUIC 分享链接；非标准传输、SS 插件及暂未支持的格式会明确跳过。GitHub runner 的测速结果受 runner 出口、测试服务和时段影响，不等于用户手机所在网络的实际速度。测速只使用受限大小的公共测试流量，不会对节点进行压力测试。质量报告只公开哈希节点 ID、协议、测速 Mbps 和聚合统计，不公开服务器地址、UUID 或密码。地区仍按节点备注/主机名关键词推测，不是 IP 地理定位。

## 本地运行

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/collector.py
```

本地生成 docs/shadowrocket.txt（Base64 订阅，按大陆可用性档位、再按实际 Mbps 排序）和 docs/quality_report.json（仅含哈希 ID 与测速统计）；订阅文件已加入 .gitignore，请勿提交。

## 配置

订阅源位于 config/sources.txt，每行一个 URL，支持 # 注释。请只添加可信来源。
